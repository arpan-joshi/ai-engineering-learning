# Linear Algebra

Linear Algebra is an important mathematical foundation for
Machine Learning and Deep Learning.

This section focuses on understanding the fundamental mathematical
operations used in AI and implementing them using Python and NumPy.

## Topics Covered

### Vectors

- Vectors
- Vector addition
- Vector subtraction
- Scalar multiplication
- Dot product

### Matrices

- Matrix representation
- Matrix addition
- Matrix subtraction
- Matrix multiplication
- Matrix transpose

### Vector Norms

- L1 Norm
- L2 Norm
- Infinity Norm

### Eigen Concepts

- Eigenvalues
- Eigenvectors
- Eigenvalue/eigenvector relationship
- Verification of eigenvectors

Understand the fundamental concepts of Linear Algebra and their
importance in Machine Learning and Deep Learning.

rather than only using ready-made library functions.
