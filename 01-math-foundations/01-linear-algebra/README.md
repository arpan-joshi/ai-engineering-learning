# Linear Algebra

Linear Algebra is an important mathematical foundation for
Machine Learning and Deep Learning.

This section focuses on understanding the fundamental mathematical
operations used in AI and implementing them using Python and NumPy.

## Topics Covered

### Vectors

- Vectors
- Vector addition
- Vector subtraction

- Dot product

### Matrices

- Matrix representation
- Matrix addition
- Matrix subtraction
- Matrix multiplication
- Matrix transpose
- Matrix inverse
- Determinant
- Matrix rank

### Vector Norms

- L1 Norm
- L2 Norm
- Infinity Norm

### Eigen Concepts

- Eigenvalues
- Eigenvectors
- Eigenvalue/eigenvector relationship
- Verification of eigenvectors

### PCA Connection

- Principal Component Analysis
- Dimensionality reduction
- Relationship between PCA and eigenvectors
- Relationship between PCA and eigenvalues

rather than only using ready-made library functions.
