# Statistics

Statistics is an important mathematical foundation for
Machine Learning and Data Science.

This section focuses on descriptive statistics,
inferential statistics, distributions, relationships
between variables, and statistical testing.

- Quartiles

- Random sampling
- Sampling distribution
- Central Limit Theorem

### Inferential Statistics

- Hypothesis testing
- Null hypothesis
- Alternative hypothesis

- Covariance
- Correlation
- Linear regression statistics
